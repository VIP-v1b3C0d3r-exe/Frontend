# Local Event Finder — Frontend

Frontend for the Local Event Finder app built with React + Vite.

## Tech Stack
- React + Vite
- React Router DOM
- TanStack Query
- React Leaflet
- CSS Modules

## Getting Started

### Prerequisites
- Node.js v18+
- npm

### Installation
git clone https://github.com/VIP-v1b3C0d3r-exe/Frontend.git
cd Frontend
npm install

### Running the app
npm run dev

## Project Structure
src/
├── api/          # backend API calls
├── components/   # reusable UI components
├── context/      # React context (auth)
├── hooks/        # custom hooks
├── pages/        # app screens
├── utils/        # helper functions
├── assets/       # images, icons
└── styles/       # global CSS

## Environment Variables
Create a .env file in the root:
VITE_API_BASE_URL=http://localhost:8080
